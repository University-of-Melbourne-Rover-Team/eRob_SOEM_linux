# URT Issues Log
This file is used to keep a log of issues in URT EtherCAT maindevice.  

**#1** ZeroErr eRob actuators always fail to enter OP mode on 1st attempt after Power On Reset (POR). This issue only occurs on the first attempt, rerunning the process clears this error, and never happens again until next POR.  
This is a known issue from the manufacturer. See link below.
